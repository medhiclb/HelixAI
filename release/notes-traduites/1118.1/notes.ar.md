# الاتصال بـ Roblox وبدء Code

- يمكن انتظار الاتصال الأولي بـ Roblox Studio لمدة تصل إلى دقيقتين. عند انتهاء المهلة، توضح الرسالة كيفية فتح لعبة وتفعيل خادم MCP داخل Studio قبل إعادة المحاولة.
- يحافظ Code على الاسم الكامل للنموذج المحدد ويمنح محركه مهلة تصل إلى دقيقة للبدء. إذا توقف المحرك أو تعذر تشغيله، يظهر سبب فشل البدء بدلاً من رسالة عدم توفر النموذج.
- توضح المساعدة أن Blender مجاني وأن أدواته المحلية لا تحتاج إلى اشتراك أو مفتاح API. وتظل خدمات التوليد الخارجية خاضعة لشروطها الخاصة.
