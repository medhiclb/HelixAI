# Roblox-Verbindung und Start von Code

- Die erste Verbindung zu Roblox Studio kann bis zu zwei Minuten warten. Bei einer Zeitüberschreitung erklärt die Meldung, wie man ein Spiel öffnet und den MCP-Server in Studio aktiviert, bevor man es erneut versucht.
- Code behält den vollständigen Namen des gewählten Modells bei und lässt seiner Engine bis zu einer Minute zum Starten. Wenn die Engine beendet wird oder nicht starten kann, ersetzt die Startursache die Meldung zum nicht verfügbaren Modell.
- Die Hilfe erklärt, dass Blender kostenlos ist und seine lokalen Werkzeuge weder ein Abonnement noch einen API-Schlüssel benötigen. Für externe Generierungsdienste gelten weiterhin deren eigene Bedingungen.
