# Roblox connection and Code startup

- The initial connection to Roblox Studio can wait up to two minutes. On timeout, the message explains how to open a game and enable the MCP server in Studio before trying again.
- Code preserves the full name of the selected model and gives its engine up to one minute to start. If the engine exits or cannot launch, the startup cause replaces the model unavailable message.
- Help clarifies that Blender is free and its local tools need neither a subscription nor an API key. External generation services remain subject to their own terms.
