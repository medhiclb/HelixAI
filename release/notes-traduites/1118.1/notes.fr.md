# Connexion Roblox et démarrage de Code

- La connexion initiale à Roblox Studio peut attendre jusqu’à deux minutes. En cas de délai dépassé, le message indique comment ouvrir un jeu et activer le serveur MCP dans Studio avant de réessayer.
- Code conserve le nom complet du modèle choisi et laisse jusqu’à une minute à son moteur pour démarrer. Si le moteur s’arrête ou ne peut pas se lancer, la cause de démarrage remplace le message de modèle indisponible.
- L’aide précise que Blender est gratuit et que ses outils locaux ne demandent ni abonnement ni clé API. Les services externes de génération restent soumis à leurs propres conditions.
