# Conexión con Roblox e inicio de Code

- La conexión inicial con Roblox Studio puede esperar hasta dos minutos. Si se agota el tiempo, el mensaje explica cómo abrir un juego y activar el servidor MCP en Studio antes de reintentar.
- Code conserva el nombre completo del modelo elegido y permite que su motor tarde hasta un minuto en iniciarse. Si el motor se detiene o no puede arrancar, la causa del inicio sustituye al mensaje de modelo no disponible.
- La ayuda aclara que Blender es gratuito y sus herramientas locales no requieren suscripción ni clave API. Los servicios externos de generación siguen sujetos a sus propias condiciones.
